# Distance Cache System - Usage Guide

## Problem
You have 109 courses and need to calculate walking distances between all building pairs. That's **approximately 5,886 API calls** (109 × 109 ÷ 2), which would cost money and use up your API quota every time you run your code.

## Solution
This caching system calculates all distances **once** and saves them to a CSV file. After that, you can look up distances instantly with **ZERO additional API calls**.

---

## Files Created

1. **`distance_cache.py`** - Core caching functions
2. **`cache_usage_example.py`** - Example script showing how to generate and use the cache
3. **`modified_functions.py`** - Reference for modifying your notebook functions
4. **`building_distances_cache.csv`** - (Generated by you) The cache file with all distances

---

## Step-by-Step Instructions

### Step 1: Generate the Cache (ONE TIME ONLY)

Run this **once** to generate the cache file:

```bash
python cache_usage_example.py
```

Then uncomment and run the generation function:

```python
# In cache_usage_example.py, uncomment:
step1_generate_cache()
```

**What this does:**
- Extracts all unique buildings from your 109 courses
- Calculates walking time between every building pair
- Saves results to `building_distances_cache.csv`

**Cost:**
- ~5,886 API calls
- ~$29.43 (at $0.005 per call)
- ~50 minutes to complete

**You only need to do this ONCE!** The cache file can be reused forever.

---

### Step 2: Modify Your Notebook

Add this cell near the top of your notebook (after imports):

```python
from distance_cache import load_distance_cache, get_walking_time_cached

# Load the cache into memory
print("Loading distance cache...")
if load_distance_cache():
    print("✓ Cache loaded successfully!")
else:
    print("ERROR: Cache not found. Run cache_usage_example.py first!")
```

---

### Step 3: Update Your `get_walking_time()` Function

Replace your existing `get_walking_time()` function with this cached version:

```python
def get_walking_time(origin, destination):
    """Uses cache instead of making API calls"""
    # Ensure proper location format
    if ", IL" not in origin:
        origin = origin + ", Urbana, IL"
    if ", IL" not in destination:
        destination = destination + ", Urbana, IL"

    # Get from cache (no API call!)
    return get_walking_time_cached(origin, destination, gmaps=None)
```

**That's it!** Your existing functions like `compute_travel_satisfaction_score()` will automatically use the cache now through the modified `get_walking_time()`.

## FAQ

### Q: What if I add new courses later?
A: If you add new buildings that aren't in the cache, `get_walking_time_cached()` will return `None`. You can either:
1. Regenerate the entire cache
2. Manually add those specific distances to the CSV file

### Q: Do I need to regenerate the cache every semester?
A: Only if new buildings are added to the course list. If it's the same 109 buildings, the cache works forever.

### Q: What if the cache file gets corrupted?
A: Just delete `building_distances_cache.csv` and run `step1_generate_cache()` again.

### Q: Can I share the cache file with teammates?
A: Yes! Once generated, anyone can use the `building_distances_cache.csv` file without making API calls.

### Q: Will this work for all 109 courses?
A: Yes, the cache will contain distances between all unique building pairs from your CSV file.

## Math Check ✓

For **N unique buildings**:
- Total API calls = N × (N - 1) ÷ 2
- For 109 buildings: 109 × 108 ÷ 2 = **5,886 calls**

Each pair is stored twice in the cache (A→B and B→A) for fast lookup, so the CSV will have ~11,772 rows.
